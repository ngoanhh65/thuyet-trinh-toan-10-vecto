# Thế giới Vectơ – Toán 10

Website thuyết trình tương tác về kiến thức Vectơ lớp 10 (bộ sách Kết nối tri thức với cuộc sống).

## Nội dung
- Khái niệm vectơ và các yếu tố cơ bản
- Tổng, hiệu hai vectơ
- Tích của vectơ với một số
- Vectơ trong mặt phẳng tọa độ
- Tích vô hướng
- Máy tính vectơ mini và câu hỏi trắc nghiệm tương tác

## Chạy website
Mở trực tiếp `index.html` bằng trình duyệt.

## Xuất bản bằng GitHub Pages
1. Mở **Settings** của repository.
2. Chọn **Pages** ở thanh bên.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main**, thư mục **/(root)** rồi nhấn **Save**.
5. Đợi GitHub Pages hoàn tất triển khai; địa chỉ website sẽ xuất hiện trong phần Pages.
